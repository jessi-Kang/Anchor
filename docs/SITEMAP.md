# 사이트맵

![사이트맵](sitemap.png)


세 언어는 같은 화면을 재사용한다. 언어는 데이터 속성이지 라우트가 아니다. 하단 탭바 없음. 설정은 홈 우상단 한 곳. 상단 왼쪽 "지금 어디" 라벨은 한 단계 위로 가는 링크(어느 화면에서도 홈까지 2탭). 화면 순서와 목적은 `docs/FLOW.md`.

```mermaid
flowchart TD
  L[/ 로그인] --> O[/onboarding/languages<br/>언어 고르기]
  O --> I
  T[/today 홈]
  T --> I[/inputs 자료]
  T --> C[/cards 발견 카드]
  T --> K[/talk 못 한 말]
  T --> G[/graph 앵커 그래프]
  T --> S[/settings]
  I --> C
  C --> G
  G --> I
```

| 라우트 | 화면 파일 | 하는 일 |
| --- | --- | --- |
| `/` | O01 | Google 로그인. 데이터 원칙 2줄 |
| `/onboarding/languages` | O02a | 시작할 언어 고르기 (여러 개 가능). 다음 → 바로 그 언어의 `/inputs/new`. 홈·설정의 "언어 추가"도 여기로. 이 페이지는 리다이렉트하지 않는다 |
| `/onboarding/kana` | O03 | 가나 6개 실제 읽기 (마이크는 버튼 뒤에 켬). 일본어 첫 카드 직전에 한 번만. 미지원·거부는 "다음에 다시 확인"으로 남기고 카드로 |
| `/onboarding/kana/module` | O03b | 가나 모듈 예고 1장. "못 읽겠어" 뒤. 카드를 잠그지 않고 "카드로" → F04 (FLOW 1′) |
| `/today` | F01 | 오늘 만난 것 큐 (자료 행: 한자 n개 · 남은 카드, 다음 카드 이유 한 줄). 켠 언어가 없으면 O02a 로. 빈 상태는 "첫 자료 넣기" 버튼 하나 |
| `/today/done` | F15 | 하루 끝. 오늘 켜진 것(한자·덩어리·내일 대기), 따로 공부한 시간 한 줄. 카드 큐가 비면 홈 대신 |
| `/inputs/new` | F02 | 붙여넣기 / 공유 시트 수신. 첫 방문엔 예시 자료 1개를 탭 한 번으로 |
| `/inputs/[id]` | F03 | 모르는 것 추출, 아는 소리로 시작할 것부터. 한자마다 "알아 / 몰라" 선택 칩 한 탭 → user_node_state ("아는 것" 수집은 여기서만) |
| `/inputs/[id]/read` | F12 | 재만남 읽기. 본 한자는 틴트, 새 한자만 진하게. 읽기 끝 → 홈 |
| `/cards/[id]` | F04 / E01 / S01 | 카드 출처 |
| `/cards/[id]/1..5` | Scene1–5 / E02–E05 / S02–S03 | 발견 5장면. 추측 입력은 정답보다 항상 먼저 |
| `/cards/[id]/speak` | F10 / E06 / S04 | 듣기 · 말하기 · 곡선 비교 |
| `/graph` | F11 | 앵커 그래프, 다음 카드 이유, 필터 |
| `/talk` | F13 | 못 한 말 한 줄 입력 |
| `/talk/[id]` | F14 | 덩어리 + 음성 루프 |
| `/settings` | — | 홈으로, 언어 켜기·끄기, 언어 추가, 계정(이메일), 로그아웃, 음성 보관 기간(기본 30일), 전체 내보내기(JSON), 계정 삭제(확인 1장). 항목별 공개·목소리 선택은 해당 기능이 생길 때 |

API 경계(초안): `/api/inputs` (생성·추출), `/api/cards` (생성·추측 기록), `/api/graph/next` (다음 카드), `/api/talk` (덩어리 생성), `/api/tts`, `/api/pitch` (브라우저 처리가 기본, 서버는 저장만), `/api/export`, `/api/account/delete`.
