# 사이트맵

세 언어는 같은 화면을 재사용한다. 언어는 데이터 속성이지 라우트가 아니다. 하단 탭바 없음. 설정은 홈 우상단 한 곳. 상단 왼쪽 "지금 어디" 라벨은 한 단계 위로 가는 링크(어느 화면에서도 홈까지 2탭). 화면 순서와 목적은 `docs/FLOW.md`.

```mermaid
flowchart TD
  L[/ 로그인] --> O[/onboarding/languages<br/>언어 고르기]
  O --> P[상황 고르기<br/>라우트 미정]
  P --> C
  O -. 선택 .-> I
  T[/today 홈]
  T --> I[/inputs 자료]
  T --> C[/cards 발견 카드]
  T --> K[/talk · /talk/past<br/>못 한 말]
  T --> S[/settings]
  I --> C
  C --> G
  G --> I
```

### 낡은 그림 (2026-09-20 판, 다시 그리기 전까지 보관)
> **이 그림은 위 mermaid 와 다르다. 다르면 위가 맞다.** 상황 고르기가 없고 언어 고르기에서 자료 넣기로 바로 간다 — 근간이 그 뒤에 바뀌었다(`README.md`). **문서 맨 위에 있었는데 아래로 내렸다**: 캡션은 그림 뒤에 읽히는데 그림은 글보다 빨리 읽혀서, 고치러 온 사람이 **틀린 그림을 먼저 믿었다.** 다시 그리는 것은 디자인 손이고 중지가 풀리면 큐에 있다.

| 라우트 | 화면 파일 | 하는 일 |
| --- | --- | --- |
| `/` | O01 | Google 로그인. 데이터 원칙 2줄 |
| `/onboarding/languages` | O02a | 시작할 언어 고르기 (여러 개 가능). 다음 → **상황 고르기**(라우트 미정, `docs/FLOW.md` 1장 2′) → 첫 카드. **자료 넣기(`/inputs/new`)는 옆에 붙은 선택 가지이지 이 길 위의 문이 아니다**(`README.md` 근간). **지금 코드는 여기서 바로 `/inputs/new` 로 보낸다 — 보낼 화면이 아직 없어서다**(`docs/STATUS.md`). **그건 현재 상태이고 이 표가 적는 것은 약속이다** — 둘이 다를 때 이 표는 약속을 적고 다른 점을 옆에 단다. 홈·설정의 "언어 추가"도 여기로. 이 페이지는 리다이렉트하지 않는다 |
| `/onboarding/kana` | O03 | 가나 6개 실제 읽기 (마이크는 버튼 뒤에 켬). 일본어 첫 카드 직전에 한 번만. 미지원·거부는 "다음에 다시 확인"으로 남기고 카드로 |
| `/onboarding/kana/module` | O03b | 가나 모듈 예고 1장. "못 읽겠어" 뒤. 카드를 잠그지 않고 "카드로" → F04 (FLOW 1′) |
| `/today` | F01 | 오늘 만날 것 큐 (자료 행: 한자 n개 · 남은 카드, 다음 카드 이유 한 줄). 켠 언어가 없으면 O02a 로. **자료가 0개인 날에도 빈 상태를 두지 않는다** — 홈은 항상 두 줄이고 둘째 줄(그래프가 고른 것)은 그날도 선다(`README.md` 근간). **지금 코드가 내는 「첫 자료 넣기」 한 화면은 명세가 아니라 버그다** — 전에 이 칸이 그걸 명세로 적고 있어서, 고치러 온 사람이 여기를 열면 지금 모양이 맞다고 읽었다 |
| `/today/done` | F15 | 하루 끝. 오늘 켜진 것(한자·덩어리·내일 또 만날 글자), 따로 공부한 시간 한 줄. 마지막 카드를 착지한 직후에만 뜬다 — 홈이 여기로 보내지 않는다 (`docs/FLOW.md` 4장) |
| `/inputs` | F19 | 지난 자료 목록. 홈에서 넘친 자료가 온다(홈은 자료 행 최대 넷). 행 = 자료 하나, 탭하면 홈의 자료 행과 같은 세 상태로 갈린다. 최근에 넣은 것이 위 |
| `/inputs/new` | F02 | 붙여넣기 / 공유 시트 수신. 첫 방문엔 예시 자료 1개를 탭 한 번으로 |
| `/inputs/[id]` | F03 | 모르는 것 추출, 아는 낱말이 붙는 것부터(가르는 축은 소리가 아니라 낱말 — `docs/FLOW.md` 1장 4). 한자마다 "알아 / 몰라" 선택 칩 한 탭 → user_node_state ("아는 것" 수집은 여기서만) |
| `/inputs/[id]/no-card` | F04a | 그 한자의 카드 문안을 못 만들었을 때. **카드 행을 만들지 않아서** `/cards/[id]` 가 아니다. 주 버튼 "다음 글자"(그 자료의 다음 후보), 없으면 "자료로". 이탈 "나중에" → 그 자료의 F03. **못 만든 글자는 주소로만 나르고 저장하지 않는다** — 그 순간의 사정이지 그 한자의 사실이 아니다 |
| `/inputs/[id]/read` | F12 | 재만남 읽기. 본 한자는 틴트, 새 한자만 진하게. 읽기 끝 → 홈. 들어오는 길은 홈의 **다 본 자료 행**이다 (`docs/FLOW.md` 4장) |
| `/cards/[id]` | F04 / E01 / S01 | 카드 출처 |
| `/cards/[id]/1..5` | Scene1–5 / E02–E05 / S02–S03 | 발견 5장면. 추측 입력은 정답보다 항상 먼저 |
| `/cards/[id]/speak` | F10 / E06 / S04 | 듣기 · 말하기 · 곡선 비교 |
| `/graph?card=` | F11 | 카드를 착지한 직후 그래프 1장. 방금 켠 한자, 판정된 「아는 것」, 다음 후보, 다음 카드 이유 한 줄. 카드 없이 열면 홈으로 — 홈에서 바로 들어오는 길은 없다 |
| `/talk/past` | F18 | 전에 못 했던 말 목록. 행 = 덩어리 하나(제목은 덩어리, 부제는 그때 쓴 한국어 한 줄), 탭 → F14. 마지막으로 말한 지 오래된 것이 위. 홈의 못 한 말 행이 덩어리가 있을 때 여기로 온다 |
| `/talk` | F13 | 못 한 말 한 줄 입력. 덩어리가 하나도 없을 때 홈 행이 바로 여기로 온다 |
| `/talk/[id]/guess` | F17 | 추측 한 줄. 답은 이 화면에 없다 (FLOW 1′) |
| `/talk/[id]` | F14 | 내 추측과 영어 문장을 나란히 + 음성 루프. 채점하지 않는다 |
| `/settings` | — | 홈으로, 언어 켜기·끄기, 언어 추가, 계정(이메일), 로그아웃, 음성 보관 기간(기준값은 `docs/SPEC.md` 6.6), 전체 내보내기(JSON), 계정 삭제 행 → `/settings/delete`. 항목별 공개·목소리 선택은 해당 기능이 생길 때 |
| `/settings/delete` | — | 계정 삭제 확인 1장. "삭제"를 입력해야 지우는 링크가 켜진다. 문구와 버튼 배치는 `docs/FLOW.md` 1′ |

API 경계: `/api/inputs`(생성·추출), `/api/cards`(생성·추측 기록), `/api/graph/next`(다음 카드), `/api/talk`(덩어리 생성), `/api/tts`, `/api/recordings`(피치는 브라우저에서 뽑고 서버는 저장만 한다), `/api/export`, `/api/account/delete`, `/api/auth/[...path]`, `/api/health`, `/api/cron/backup` · `/api/cron/voice`. 어디까지 만들어졌는지는 `docs/STATUS.md`.
