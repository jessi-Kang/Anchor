# Anchor 로고 (A안 확정)

의미: 아는 것(채워진 점)에서 선이 내려가 새 것(두 점)을 끌어올린다. 닻이자 앵커 그래프의 엣지.

- anchor-mark.svg — 기본 마크 (잉크 + 앵커 블루)
- anchor-mark-mono.svg — 단색
- anchor-lockup.svg — 마크 + 워드마크 (Noto Sans KR 700)
- anchor-appicon.svg — 다크 배경 앱 아이콘 / PWA manifest 아이콘 / 파비콘 원본
- logo-sheet.png — 미리보기

색: #2A2D33 잉크, #5C7CB0 앵커 블루. 100 그리드: 점 r=11, 선 9, 호 반지름 28, 끝점 r=7.
PWA: appicon을 512/192로 내보내고 maskable 지정. 파비콘은 32px에서 마크만.

`alternatives/`는 검토 후 탈락한 시안(B~G). 참고용이며 제품에 쓰지 않는다.
