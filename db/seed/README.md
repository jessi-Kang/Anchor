# 영어 씨앗 40장 — 선정 기준

O04(온보딩 3장)에서 3분 안에 넘기는 카드. 목적은 "가르치기"가 아니라 **앵커 그래프에 첫 "아는 노드"를 심는 것**이다.
그래프는 "아는 것 + 1"로 다음 카드를 정하니, 첫날 아는 노드가 없으면 아무것도 시작하지 못한다.

## 왜 단어가 아니라 부품·덩어리인가

- 그래프의 노드는 단어가 아니라 **부품**(어근·접사·덩어리)이다. 단어 40개를 심으면 노드 40개지만, 어근 하나를 심으면 그 어근이 든 단어 수십 개가 "반쯤 아는 것"이 된다.
- 어근은 영어 → 스페인어 브릿지(`cognate` 엣지)의 출발점이다. 덩어리는 영어 대화 루프(F13–F14)의 재료다. 둘 다 MVP 다음 단계에서 바로 쓰인다.

## 구성: 어근·접사 22 + 대화 덩어리 18

### 어근·접사 22장 (접두사 9 · 어근 9 · 접미사 4)

기준 (넷 다 만족해야 들어간다):

1. **업무·학술 어휘에서 생산성이 높다.** Jessi가 회의·수업·이메일에서 이미 쓰는 단어 3개 이상에 들어가야 한다 (`words` 필드). 원칙 2: 영어의 앵커는 업무 어휘.
2. **라틴계라 스페인어 대응이 규칙적이다.** `es` 필드에 그 대응을 적는다 (-tion → -ción, -ity → -dad, spect → -spec-). 그리스계·게르만계 부품은 이번엔 뺀다. 브릿지가 안 되기 때문.
3. **뜻이 한 줄로 떨어진다.** "to look", "before"처럼 기본 2,000어 안에서 한 구절로 정의된다. 뜻이 여러 갈래인 부품(예: `-ment`, `con-`)은 뺀다.
4. **모양이 단어 안에서 눈에 보인다.** 변형이 심해 알아보기 어려운 어근(`cap/cep/ceiv`)은 뺀다. 발견 카드의 "부품 분해"가 성립해야 한다.

### 대화 덩어리 18장 (태도 9종 × 2)

기준:

1. **SPEC 5장의 기능 분류 9종(내적 태도 / 기억 / 의도 / 능력 / 제안 / 원인 / 설명 / 확인 / 강조)을 각 2장씩.** 이 9종이 세 언어 공통의 덩어리 분류 축이고, "못 한 말"의 대부분은 단어가 아니라 태도 표현이다. 씨앗이 9종을 다 덮어야 첫 대화 루프에서 어떤 태도가 들어와도 인접 노드가 있다.
2. **한국어 말끝 하나에 대응한다** (`ko_anchor` 필드: ~인 것 같다, ~할 텐데, ~거든). 이게 가장 강한 한국어 앵커라서, 카드의 후킹을 "이 상황에서 한국어로 뭐라고 하나"로 만들 수 있다.
3. **Jessi의 상황(회의·학위 수업·이메일)에서 실제로 나온다.** 예문은 전부 그 장면이다.
4. **덩어리 그대로 소리 내는 단위다.** 두 단어 이상, 연음이 걸리는 것 우선 ("push back", "the thing is"). 사운드 루프에서 그대로 쓴다.

같은 태도의 두 장은 **강도가 다르게** 골랐다 (`intensity` 1 → 2). Rikus 가이드의 Level Up 축을 그래프의 `intensity` 엣지로 옮기기 위해서다.

## 순서

어근·접사 먼저, 덩어리 나중. 어근은 "떠올랐어"가 많이 나와 시작이 가볍고, 덩어리는 정의를 읽는 시간이 조금 더 든다.
접두사 → 어근 → 접미사 순은 단어 앞에서 뒤로 읽는 순서다.

## 뺀 것과 이유

| 후보 | 이유 |
| --- | --- |
| `con-`, `-ment`, `ex-` | 뜻이 여러 갈래 (기준 3) |
| `cap/cep/ceiv`, `fac/fic/fect` | 변형이 심해 단어 안에서 안 보인다 (기준 4) |
| `bio-`, `-logy`, `tele-` | 그리스계. 스페인어 대응은 되지만 라틴 어근 브릿지 규칙과 다르다. v1.5에서 |
| follow up, heads up, circle back | 업무에서 자주 쓰지만 9종 축에 두 자리씩 채우고 나면 자리가 없다. 인풋 레이어에서 자연히 들어온다 |
| you know, sort of | 태도가 흐릿하다 (기준 1). 대화 루프에서 채움말로 따로 다룬다 |

## 한자 씨앗 40장 (ja-seed.json) — 선정 기준

일본어 그래프의 첫 "아는 한자"를 심는다. 영어 씨앗과 같은 구조지만 판정하는 것은 **소리**다(뜻은 묻지 않는다).

1. **한국어 한자어에 흔히 들어가는 글자.** Jessi가 소리로 이미 아는 한자어(협력, 시간, 회의, 업무, 설명…)에서 뽑는다. 앵커는 글자가 아니라 그 소리다 (`ko_word`의 `ko_sound`).
2. **받침 → 음독 패턴이 골고루.** 받침 없음(1모라), ㄴ·ㅁ→ん, ㄱ→く, ㅂ→う, ㄹ→つ/ち, ㅇ→う/い. 카드 순서를 패턴 묶음으로 두어 규칙 표 없이도 순서만으로 패턴이 드러나게 한다. `pattern` 필드는 그래프 엣지(`ko_sound_onyomi`)용이고 화면에 절대 쓰지 않는다.
3. **음독이 규칙적이고 하나로 떨어진다.** 예외 음독(立 립→りつ 등)이나 음독이 여럿인 글자는 뺀다. 첫날은 규칙이 보여야 한다.
4. **예시 단어가 JLPT N5~N4 빈도 안에 있고 한국어 한자어와 같은 조합이다.** 協力·時間·会議처럼 한국어와 일본어가 같은 두 글자를 쓰는 단어. 뒤집었을 때 한 번에 두 글자가 "아는 것"으로 연결된다.

뒤집으면 보이는 것: 음독(예 きょう) · 예시 단어 + よみがな(協力 きょうりょく) · 한국어 앵커 한 줄(협력의 협). 한국어 뜻풀이는 없다(원칙 2: 한국어는 앵커 호출용).

## 갱신

`en-seed.json` 또는 `ja-seed.json`을 고치고 `pnpm db:seed`. 같은 `(lang, kind, key)`는 갱신, 새 것만 추가. 이미 판정한 사용자 상태는 그대로 남는다.
